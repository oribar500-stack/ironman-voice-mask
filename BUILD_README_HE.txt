איך ליצור את ה-JAR:

1. ודא שמותקן Java 21 (64-bit).
2. פתח את התיקייה הזו.
3. לחץ פעמיים על BUILD_JAR.bat.
4. בפעם הראשונה הסקריפט יוריד Gradle ואת תלויות הפרויקט מהאינטרנט.
5. אם הבנייה מצליחה, יופיע בתיקייה הראשית:

   ironman-voice-mask-1.0.0.jar

זה הקובץ שאמור להיכנס לתיקיית mods של Minecraft.

אם מופיע BUILD FAILED, העתק את כל השגיאה ושלח אותה בצ'אט.
